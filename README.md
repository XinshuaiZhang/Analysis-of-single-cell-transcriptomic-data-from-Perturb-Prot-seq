# Analysis-of-single-cell-transcriptomic-data-from-PerturbPro-seq
The code contained in this repository is primarily designed to support the single-cell transcriptomic analyses presented in the publication *“PerturbPro-seq: Multimodal Single-Cell CRISPR Screens for Simultaneous Readouts of Surface and Intracellular Proteins and mRNAs.”* Specifically, it encompasses data processing, quality control, normalization, dimensionality reduction, clustering, and downstream differential expression analyses required for the interpretation of PerturbPro-seq single-cell transcriptomic datasets.
